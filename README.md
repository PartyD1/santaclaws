# Mainstreet

Mainstreet is a 24-hour hackathon build for a four-claw autonomous sales team powered by NemoClaw and Nemotron.

The repo is intentionally small:

- `agents/`: Python 3.11 NemoClaw claws, shared tools, prompts, and setup scripts.
- `dashboard/`: Next.js 14 dashboard shell.
- `nemoclaw/`: NemoClaw/OpenShell setup notes and runtime policy docs.
- `docs/`: execution spec and progress tracking.

Follow `docs/Mainstreet_NemoClaw_Codex_Execution_Spec.md` and update `docs/PROGRESS.md` after each task.
