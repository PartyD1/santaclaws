# Mainstreet Agents

Python 3.11 package for NemoClaw claws.

Setup:

1. Create a virtual environment from the repo root.
2. Install dependencies with `pip install -r agents/requirements.txt`.
3. Copy `.env.example` to `.env` and fill the keys from the current task.

Task 8 starts the first real implementation by adding the Nemotron client in `agents/shared/nemotron_client.py`.
