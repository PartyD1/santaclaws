# NemoClaw Network Policy

Allow outbound access from the NemoClaw/OpenShell sandbox to:

- Supabase project API and Realtime domains
- Apify API
- Vercel API
- Resend API
- Discord webhook and bot API
- Google Calendar APIs
- Vapi APIs, only if the stretch task is attempted
- NemoClaw/OpenShell inference route for Nemotron

Task 0 should replace this list with exact hostnames from the created accounts.
