# Mainstreet Agent Memory

Real-time memory vault for the four NemoClaw agents powering the Mainstreet autonomous sales team.

## Pipeline

[[Scout Memory]] → [[Designer Memory]] → [[Pitcher Memory]] → [[Closer Memory]]

## Agents

| Memory | Role | Docs |
| --- | --- | --- |
| [[Scout Memory]] | Finds and scores local auto repair shop leads | [[Scout Soul]] · [[Scout Tools]] · [[Scout Agents]] · [[Scout Heartbeat]] |
| [[Designer Memory]] | Generates website mockups for qualified leads | [[Designer Soul]] · [[Designer Tools]] · [[Designer Agents]] · [[Designer Heartbeat]] |
| [[Pitcher Memory]] | Drafts and queues personalized outreach emails | [[Pitcher Soul]] · [[Pitcher Tools]] · [[Pitcher Agents]] · [[Pitcher Heartbeat]] |
| [[Closer Memory]] | Classifies inbound replies and books meetings | [[Closer Soul]] · [[Closer Tools]] · [[Closer Agents]] · [[Closer Heartbeat]] |

## Usage

- Open this folder in Obsidian → graph view shows agent relationships
- Memory notes auto-update as claws run — each heartbeat appends a new entry
- Search `#error` to find recent failures across all agents
