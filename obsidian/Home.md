# Mainstreet Agent Memory

Real-time memory vault for the four NemoClaw agents powering the Mainstreet autonomous sales team.

## Pipeline

[[Scout Memory]] → [[Designer Memory]] → [[Pitcher Memory]] → [[Closer Memory]]

## Agents

| Agent | Role |
| --- | --- |
| [[Scout Memory]] | Finds and scores local auto repair shop leads |
| [[Designer Memory]] | Generates website mockups for qualified leads |
| [[Pitcher Memory]] | Drafts and queues personalized outreach emails |
| [[Closer Memory]] | Classifies inbound replies and books meetings |

## Usage

- Open this folder in Obsidian → graph view shows agent relationships
- Notes auto-update as claws run — each heartbeat appends a new entry
- Search `#error` to find recent failures across all agents
